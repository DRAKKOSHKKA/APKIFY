# 📱 Apkify — Мобильное расписание для iPhone (Expo SDK 57)

Современное мобильное приложение для студентов и преподавателей **Альметьевского профессионального колледжа** (и других учебных заведений на платформе `it-institut.ru`), разработанное на стеке **Expo SDK 57**, **React Native 0.86** и **TypeScript**.

Интерфейс спроектирован по гайдлайнам **Apple Human Interface Guidelines (iOS HIG)** с поддержкой адаптивной тёмной темы, эстетики **Liquid Glass (iOS 27 Tinted Glass)**, офлайн-режима и встроенного комплекса самотестирования.

---

## ✨ Ключевые возможности

- ⚡ **Прямое взаимодействие с сайтом колледжа:** Нативный сетевой стек iOS обращается напрямую к `it-institut.ru` (минуя ограничения CORS браузера).
- 🔍 **Умный поиск:** Мгновенный поиск групп, преподавателей и кабинетов через `KeySearch API` с сохранением в «Избранное».
- 🕒 **Индикатор текущей пары:** Автоматическое определение текущего занятия с живым отсчетом оставшегося времени («Идёт • ост. 24 мин») и времени до начала следующей пары.
- 👥 **Интеллектуальные подгруппы:** Отображение бейджей `1-я подгруппа` / `2-я подгруппа` только тогда, когда предмет фактически разделен по подгруппам (без визуального шума и дублирования названия группы).
- 🔔 **Уведомление о начале дня:** Если первой пары в расписании нет, приложение информирует: _«Первой пары нет — ко 2-й паре (к 09:30)»_.
- 💾 **Автономность и офлайн-кэш:** Сохранение расписания в `AsyncStorage`. Приложение мгновенно открывается в подвальных аудиториях без интернета и предупреждает об обновлениях на сервере.
- 🔔 **Расписание звонков:** Встроенная таблица стандартных звонков и специального расписания для субботы (по 60 минут).
- 🎨 **Apple Design & Liquid Glass:** Единые squircle-скругления Apple HIG, размытие `BlurView`, группированные настройки в стиле iOS Settings.
- 🛠️ **Инженерное Debug-меню:** Скрытая панель (открывается по **7 тапам** на версию приложения) с эмуляцией времени (**Time Travel**) и живым комплексом тестирования API, формулы недель и AsyncStorage.

## 💻 Развертывание проекта на локальном ПК (Windows / macOS / Linux)

### 1. Системные требования

- **Node.js**: версия `20.x` LTS или `22.x` ([скачать с nodejs.org](https://nodejs.org/)).
- **Git**: консольный клиент Git ([скачать с git-scm.com](https://git-scm.com/)).
- **Смартфон**: iPhone с установленным бесплатным приложением **Expo Go** из App Store (или Android-смартфон из Google Play).

---

### 2. Клонирование и установка зависимостей

Откройте терминал (PowerShell / Command Prompt на Windows, Terminal на macOS/Linux) и выполните:

```bash
# Клонируем репозиторий
git clone https://github.com/DRAKKOSHKKA/apkify.git

# Переходим в папку проекта
cd apkify

# Устанавливаем зависимости
npm install
```

---

### 3. Настройка локальной сети (`.env.local`)

> [!IMPORTANT]
> Если на вашем компьютере установлены **VMware**, **VirtualBox**, **Docker** или **WSL**, они создают виртуальные сетевые адаптеры. Expo CLI может ошибочно выбрать виртуальный IP (например, `192.168.254.1`), к которому телефон не сможет подключиться.

1. Создайте в корне проекта файл `.env.local` (скопировав шаблон `.env.example`):
    ```bash
    # На Windows (PowerShell):
    copy .env.example .env.local
    ```
2. Узнайте ваш настоящий локальный IP-адрес:
    - В Windows выполните команду: `ipconfig`
    - Найдите адаптер вашей домашней сети (**Беспроводная сеть / Wi-Fi** или **Ethernet**) и скопируйте строку **IPv4-адрес** (обычно `192.168.1.X` или `192.168.0.X`).
3. Откройте `.env.local` и укажите этот IP:
    ```ini
    REACT_NATIVE_PACKAGER_HOSTNAME=192.168.1.X
    ```

_(Файл `.env.local` автоматически добавлен в `.gitignore` и не попадет в публичный репозиторий)._

---

### 4. Запуск сервера разработки

#### Вариант A. Локальная сеть Wi-Fi (Быстрый запуск)

Если компьютер и телефон подключены к **одному домашнему Wi-Fi роутеру**:

```bash
npm start
```

1. В консоли появится QR-код.
2. Откройте стандартную камеру на iPhone и наведите на QR-код.
3. Нажмите на всплывающее уведомление **«Открыть в Expo Go»**.

#### Вариант B. Режим туннеля (Для студенческих / публичных сетей)

Если вы запускаете проект в колледже, через мобильную точку доступа (LTE) или если роутер блокирует связь между устройствами (AP Isolation):

```bash
npm run tunnel
# или:
npx expo start --tunnel
```

_(В проект уже встроен пакет `@expo/ngrok`, туннель поднимется автоматически)._

---

### 5. Горячие клавиши в терминале Metro

Когда сервер запущен, в терминале доступны быстрые команды:

- `r` — мгновенно перезагрузить приложение на телефоне (Reload).
- `m` — открыть меню разработчика Expo на экране телефона.
- `j` — открыть отладчик Chrome / Hermes Debugger.
- `c` — очистить кэш сборщика Metro и перезапустить сервер.

## 🍏 Сборка нативного IPA для iPhone на Windows (100% Бесплатно)

Напрямую скомпилировать `.ipa` в Windows невозможно из-за отсутствия сред компиляции Apple Clang. Для этого проекта настроена **полностью автоматическая и бесплатная облачная сборка через GitHub Actions** на процессорах Apple Silicon (`macos-14`).

Подробнейшая пошаговая инструкция с иллюстрациями и установкой через **Sideloadly** и **AltStore** находится в документе:
👉 **[Руководство по сборке и установке iOS IPA на Windows](file:///v:/Apkify/docs/IOS_BUILD_GUIDE.md)**

### Краткий алгоритм:

1. Сделайте `git push` ваших изменений в репозиторий.
2. Откройте вкладку **Actions** в GitHub и нажмите **«Run workflow»** у воркфлоу **Build iOS IPA (Free CI)**.
3. Через ~6 минут скачайте готовый архив **`Apkify-iOS-IPA`** из раздела Artifacts.
4. Установите `Apkify.ipa` на свой iPhone через **Sideloadly** на Windows, введя личный бесплатный Apple ID.

## ⚙️ Управление версиями (Централизованно)

Для обновления версии приложения во всем интерфейсе (экран настроек, модальные окна, отладочная информация) достаточно изменить одну строку в файле [`src/constants/appInfo.ts`](file:///v:/Apkify/src/constants/appInfo.ts):

```typescript
export const APP_CONFIG = {
  name: "Apkify",
  version: "1.A1", // <-- измените здесь, и версия обновится везде
  ...
};
```

## 🔍 Скрытое Debug-меню (Пасхалка)

В приложение встроен полноценный отладочный инструмент:

1. Перейдите во вкладку **«Профиль»** (Настройки).
2. Прокрутите в самый низ до строчки версии: `Apkify v1.A1`.
3. Быстро нажмите на эту строку **7 раз подряд**.
4. Откроется окно разработчика **Debug Console**:
    - **Эмуляция времени (Time Travel):** Позволяет протестировать отображение пар в любой день недели и час (например, проверить подсветку пары в понедельник в 08:15).
    - **Комплекс самотестирования:** Запуск живых тестов связи с сервером, формулы вычисления номера недели, парсера HTML, хранилища AsyncStorage и токенов оформления.

## ❓ Часто задаваемые вопросы (Troubleshooting)

<details>
<summary><b>1. Ошибка "Refused to load personal environment variables from a non-.local env file"</b></summary>

В современных версиях Expo CLI переменная `REACT_NATIVE_PACKAGER_HOSTNAME` считается приватной. Она должна быть записана именно в файле `.env.local`, а не в `.env`. Просто скопируйте `.env.example` в `.env.local`.

</details>

<details>
<summary><b>2. Expo Go долго грузится или пишет "Could not connect to server"</b></summary>

- Проверьте, что в `.env.local` указан именно адрес вашего Wi-Fi адаптера (из `ipconfig`), а не виртуальный IP от VMware/VirtualBox.
- Убедитесь, что в Windows Defender Брандмауэре разрешен входящий трафик для Node.js на порту `8081`.
- Если вы находитесь в общественной сети или сети колледжа, используйте режим туннеля: `npm run tunnel`.
  </details>

<details>
<summary><b>3. Ошибка модуля "node:stream"</b></summary>

В React Native нет стандартной библиотеки Node.js. Поэтому устаревший пакет `cheerio` был полностью заменен на легковесный и нативный `node-html-parser`, который работает с феноменальной скоростью на движке Hermes.

</details>

<details>
<summary><b>4. Как полностью очистить кэш Metro?</b></summary>

Выполните команду:

```bash
npx expo start -c
```

</details>
