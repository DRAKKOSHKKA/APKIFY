# Расписание АПК для iPhone (Expo / React Native)

Мобильное приложение для просмотра расписания занятий **Альметьевского профессионального колледжа** (и других заведений на платформе `it-institut.ru`), разработанное на **Expo SDK 57** для iPhone и Android.

---

## 📱 Возможности приложения

1. **Прямое взаимодействие с сайтом без CORS:**
    - Автоматический парсинг расписания с сайта `https://it-institut.ru`.
    - Мобильное приложение на iOS отправляет запросы через нативный стек (`NSURLSession`), минуя ограничения CORS браузера.

2. **Живой поиск групп, преподавателей и кабинетов:**
    - В реальном времени ищет по базе колледжа через `KeySearch API`.
    - Фильтры по типу: _Группы_, _Преподаватели_, _Кабинеты_.
    - Быстрые подсказки популярных групп (21 нмо, 21 нмср, 21 нпк и др.).

3. **Офлайн-режим (AsyncStorage):**
    - Расписание кэшируется на устройстве и открывается мгновенно даже без интернета (в метро, в подвальных кабинетах).
    - При наличии сети данные автоматически обновляются в фоне.

4. **Индикатор текущей пары («Идёт сейчас»):**
    - Сверяет системные часы iPhone со временем звонков пар.
    - Подсвечивает пару зеленым бейджем с отсчетом оставшегося времени (например, «Идёт • ост. 18 мин»).
    - Предупреждает о следующей паре («Через 15 мин»).

5. **Навигация по неделям:**
    - Автоматически извлекает все 17 недель семестра с их `WeekId`.
    - Возможность просматривать расписание на любую неделю вперед или назад.

6. **Расписание звонков:**
    - Встроенная таблица звонков 1–8 пар с указанием начала, конца и длительности перемен.

7. **Избранное:**
    - Возможность сохранять группы и преподавателей в «Избранное» (звёздочка в шапке) для переключения в 1 тап.

---

## 🚀 Как запустить на iPhone

1. Установите бесплатное приложение **Expo Go** из App Store на ваш iPhone.
2. Убедитесь, что ваш компьютер и iPhone подключены к **одной Wi-Fi сети**.
3. В терминале в папке `v:\Apkify` запустите команду:
    ```bash
    npx expo start
    ```
4. Наведите камеру iPhone на появившийся в терминале **QR-код** и нажмите на баннер «Открыть в Expo Go».
5. Приложение запустится на вашем телефоне! Любые изменения в коде будут мгновенно обновляться на экране (Fast Refresh).
