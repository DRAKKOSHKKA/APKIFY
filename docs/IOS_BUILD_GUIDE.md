# 🍏 Руководство: Сборка и установка iOS IPA на Windows

Это руководство подробно описывает, как получить готовый файл **`.ipa`** приложения **Apkify** и установить его на реальный iPhone с компьютера под управлением **Windows**, **без покупки Mac** и **без платной подписки Apple Developer ($99/год)**.

---

## 📌 Как это устроено?

Для компиляции нативного кода iOS требуются фирменные утилиты Apple (`xcodebuild`, Apple Clang, нативный iOS SDK), доступные исключительно в операционной системе **macOS**. На Windows напрямую запустить Xcode невозможно.

**Решение:**
Мы используем **GitHub Actions**. Так как репозиторий проекта размещен на GitHub, мы задействуем бесплатные облачные виртуальные машины GitHub на базе процессоров Apple Silicon (**macOS 14**). Они бесплатно собирают проект, формируют неподписанный `.ipa` и сохраняют его в раздел артефактов для скачивания.

---

## 🚀 Шаг 1. Получение IPA через GitHub Actions

В проекте уже настроен автоматический рабочий процесс [`.github/workflows/build-ipa.yml`](file:///v:/Apkify/.github/workflows/build-ipa.yml).

### Запуск сборки:

1. Загрузите последние изменения вашего кода в репозиторий GitHub:
    ```bash
    git add .
    git commit -m "Подготовка релиза v1.A1"
    git push origin main
    ```
2. Откройте ваш репозиторий в браузере: `https://github.com/DRAKKOSHKKA/apkify`.
3. Перейдите на вкладку **Actions** в верхнем меню.
4. В списке слева выберите воркфлоу **Build iOS IPA (Free CI)**.
5. Нажмите кнопку справа **Run workflow** -> выберите ветку `main` -> нажмите зеленую кнопку **Run workflow**.
6. Запустится сборка на macOS раннере. Время компиляции составляет обычно **5–8 минут**.

### Скачивание готового файла:

1. Нажмите на завершившийся запуск (он будет отмечен зеленой галочкой `✓`).
2. Прокрутите страницу в самый низ до блока **Artifacts** (Артефакты).
3. Нажмите на **`Apkify-iOS-IPA`** — начнется скачивание ZIP-архива.
4. Распакуйте скачанный архив на вашем ПК: внутри будет готовый файл **`Apkify.ipa`**.

## 📲 Шаг 2. Установка IPA на iPhone с Windows

Так как IPA собран без платного сертификата App Store, его необходимо подписать вашим бесплатным Apple ID при установке (Sideloading).

---

### Вариант A. Sideloadly (Рекомендуемый для Windows)

**Sideloadly** — это самая простая и стабильная бесплатная программа под Windows для установки любых IPA-файлов на iPhone.

1. **Подготовка на Windows:**
    - Скачайте и установите **Sideloadly** с официального сайта: [sideloadly.io](https://sideloadly.io).
    - Убедитесь, что на ПК установлены официальные версии **iTunes** и **iCloud** для Windows (не из Microsoft Store, а стандартные установщики от Apple, ссылки есть на сайте Sideloadly).
2. **Подключение iPhone:**
    - Подключите iPhone к компьютеру через USB-кабель.
    - На экране iPhone появится запрос: «Доверять этому компьютеру?» — нажмите **«Доверять»** и введите пароль разблокировки.
3. **Установка приложения:**
    - Откройте Sideloadly. В поле **iDevice** должен определиться ваш iPhone.
    - Перетащите мышкой файл `Apkify.ipa` в окно Sideloadly (или нажмите на иконку IPA и выберите файл).
    - В поле **Apple ID** введите ваш личный адрес Apple ID (iCloud).
    - Нажмите кнопку **Start**.
    - Sideloadly запросит пароль от Apple ID и код двухфакторной аутентификации (данные отправляются напрямую на защищенные серверы Apple для генерации бесплатного сертификата разработчика на 7 дней).
    - Дождитесь надписи `Done!`. Иконка **Apkify** появится на домашнем экране iPhone.
4. **Первый запуск на iPhone:**
    - Перейдите в **Настройки iPhone** -> **Основные** -> **VPN и управление устройством**.
    - В разделе «ПО разработчика» нажмите на ваш Apple ID.
    - Нажмите **«Доверять [ваш email]»**.
    - Если у вас iOS 16+: перейдите в **Настройки** -> **Конфиденциальность и безопасность** -> прокрутите вниз до **«Режим разработчика»** -> включите его и перезагрузите телефон.
    - Теперь приложение запускается нативно без Expo Go!

> [!TIP]
> В Sideloadly можно включить опцию **«Wi-Fi Sideloading»**, и приложение будет автоматически переподписываться по домашней сети Wi-Fi раз в неделю без подключения кабеля!

---

### Вариант B. AltStore / AltServer

Если вы уже используете инфраструктуру **AltStore**:

1. Установите **AltServer** на Windows ([altstore.io](https://altstore.io)).
2. Подключите iPhone по кабелю и установите приложение AltStore.
3. Отправьте `Apkify.ipa` на iPhone (через Telegram «Избранное», iCloud Drive или AirDrop).
4. Откройте приложение AltStore на iPhone, перейдите во вкладку **My Apps**, нажмите `+` в левом верхнем углу и выберите `Apkify.ipa`.

---

### Вариант C. TrollStore (Для iOS 14.0 – 17.0)

Если на вашем устройстве установлен **TrollStore**:

1. Отправьте `Apkify.ipa` на iPhone.
2. Откройте файл через TrollStore -> нажмите **Install**.
3. Приложение установится **навсегда**, без необходимости переподписывать каждые 7 дней и без ограничений по количеству установленных приложений.

## ☁️ Шаг 3. Альтернатива: Облачная сборка через EAS Build

Если вы не хотите использовать GitHub Actions, можно использовать бесплатные облачные мощности Expo:

1. Зарегистрируйтесь на [expo.dev](https://expo.dev).
2. В терминале в папке `v:\Apkify` выполните:
    ```bash
    npx eas-cli login
    ```
3. Инициализируйте проект в EAS:
    ```bash
    npx eas-cli project:init
    ```
4. Запустите сборку для симулятора или внутреннего тестирования:
    ```bash
    npx eas-cli build --platform ios --profile preview
    ```
    Файл `eas.json` уже настроен в корне проекта.

## 🔄 Как выпускать новые версии приложения

1. Откройте [`src/constants/appInfo.ts`](file:///v:/Apkify/src/constants/appInfo.ts) и измените номер версии (например, `"1.A2"`).
2. Закоммитьте изменения:
    ```bash
    git commit -am "Релиз v1.A2"
    git push origin main
    ```
3. Перейдите в GitHub Actions и запустите воркфлоу **Build iOS IPA (Free CI)**.
4. Скачайте новый IPA и обновите приложение через Sideloadly поверх старого — все ваши сохраненные группы и настройки сохранятся!
